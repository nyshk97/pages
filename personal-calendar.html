personal-calendar

personal-calendar は、生天目 翼（nyshk97）が自分の Google カレンダーを読み書きするためだけに使う、個人用のツールです。一般には提供していません。

プライバシーポリシー

  • Google カレンダーのデータは、本人の操作のために本人のパソコン上でだけ読み書きします。
  • データを第三者に送ったり、売ったり、広告に使ったりしません。
  • ログインの情報は本人のパソコンにだけ保存し、使わなくなったら削除します。
  • Google API から受け取ったデータの扱いは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
